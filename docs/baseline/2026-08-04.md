## API and data-integrity observations

- `D1R2Store` performs request-time schema DDL.
- The update path can advance D1 metadata independently of R2/version writes.
- Live `replaceCurrent` can change bytes behind an existing version number.
- CLI state uses direct synchronous writes without a lock, fsync, or atomic
  rename.
- Production has no required CI or deploy gate in the imported baseline.

## Baseline limitations

This is local evidence, not a production or multi-region benchmark. D1 Time
Travel, environment approvals, independent staging restore, canary observation,
and Cloudflare account-level policy require operator-owned non-production and
production resources and are tracked separately from executable repository
verification.
